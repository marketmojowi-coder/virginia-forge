# Virginia Forge

Free public index: Thomas Jefferson's 23 drawings for Richmond (1779–1809), laid out together as a puzzle map. Each piece is a schematic rendering drawn for this index (no manuscript image is reproduced) and links to the original record at the Massachusetts Historical Society (Coolidge Collection of Thomas Jefferson Manuscripts). No sign-in, no payment, no database.

Files: `public/index.html` (the whole page; renderings drawn in code).
Rebuild: in the project, `python3 -I virginia-forge/build_forge.py`, then copy `Virginia_Forge.html` into this kit (make_site step in DEPLOY.md).
